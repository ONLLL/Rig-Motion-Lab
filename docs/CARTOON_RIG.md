# 卡通 / Q 版单段骨骼

本轮在 0.4.0 基础上增加可逆的项目级骨架模板。不是图像生成或自动识别角色，也不是皮肤网格绑定。

## 使用

1. 打开角色项目，进入关节 / 骨架页面，点击明显的「标准人体」或「卡通·Q版像素」选择。
2. 卡通默认将手臂设成整段；可用预设或逐条肢体选择，手臂与腿可以分别保留双段或使用单段。并非所有卡通角色都必须使用相同骨架。
3. 单段只显示连接点和末端，不显示可拖动的肘 / 膝。将连接点放在肩 / 髋或实际附件枢轴位置，末端放在整只手 / 脚的末端，确认骨架。
4. 为完整手臂 PNG 选择 l_arm / r_arm 绑定，为整腿 PNG 选择 l_leg / r_leg。素材 A 点设在连接点，B 点沿肢体轴向；素材保持刚性，不会为了接近目标拉长。
5. 使用待机、行走、攻击或跳跃参数预览；转换为可编辑关键帧后，可以旋转整段或拖动末端。末端目标投影到固定骨长圆周，无法达到的目标会如实报告误差。
6. 保存项目再打开仍保留模板；图像预览、PNG / GIF / 图集导出使用同一拓扑与素材变换。

## 可逆与旧项目

旧项目缺省仍为标准双段，原来的 18 个标准标注、双骨 IK 和存储格式兼容读取。
模板切换不删除历史中间标注、动作库、校正轨道或素材绑定；它们仅在简化拓扑中隐藏或不生效。切回标准恢复原有数据。新单段角度轨道和旧双段轨道分别保存，在不同模式中按对应拓扑生效。
旧上臂 / 前臂 PNG 仍可兼容渲染，它们跟随整段刚性转动，不能自动变成一张完整卡通手臂。建议为新角色绑定整段素材，先预览接缝再导出。改变骨长、手工编辑动作本身仍是实际编辑，并不因切换模板自动撤销；可使用会话撤销或工程备份。

## 边界

- 极短单段经过骨长编辑后，切回双段可能需要先增大骨长或撤销编辑：每个双段分支最短为 0.008 个绑定高度单位。系统明确拒绝不合法切换，不会悄悄改标注。
- 单段腿不会弯膝，因此低蹲、跳跃和走路脚底接触更容易产生不可达目标或滑步；诊断不是物理锁脚承诺。
- 没有自动补全遮挡图像、蒙皮权重、弹性变形、角色识别或专业动画质量保证。
- 合成素材图像验证能证明渲染路径与固定长度一致，但不能替代用户真实像素角色的枢轴、接缝、层级和动作美术验收。
- 未新增远程模型服务、API Key 或付费调用。
