## 界面检查方法

交付环境的 Chromium 管理策略禁止直接导航 localhost。未改动或禁用这一策略。检查使用本地HTML/CSS/JS文档，通过Python绑定转发该文档的本地API请求与图片字节；后端仍是运行中的真实HTTP服务。

因此这些检查是**浏览器DOM交互 + Python HTTP桥接**，不是完整原生浏览器网络端到端测试。代码中的 `tools/browser_smoke.py` 清楚记录了该测试方式。

界面截图展示程序绘制素材和数值轨道，不是AI生成质量展示，也不是真人动捕成功证明。

## 验收指标的含义

接近零的骨长误差：关节运动没有被偷偷拉长。接近零的支撑期滑移：在当前数学接触标记和模板下，世界坐标的支撑脚保持稳定。它们不能证明脚底美术贴图、膝盖弯曲美感、角色力度或遮挡关系正确。

动画观感需要独立验收，尤其是初始站姿、关节位置、武器连接点和动作阶段时间。
