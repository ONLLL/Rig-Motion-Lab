# 实验架构

```
Rig / 固定初始关节、拓扑、骨长
        +
Motion / 参数、参考轨迹、少量控制关键点
        ↓
lab.motion / 目标轨迹、root、接触
lab.reference / 局部角度重定向、固定比例
        ↓
math2d.two_bone_ik / 不伸长骨骼、保留不可达误差
        ↓
Pose frames / 世界与显示坐标、接触、目标、事件
        +
Part / 同一 PNG、A/B 锚点、缩放、偏移、图层
        ↓
renderer.part_matrix / 一次性的初始纹理比例 + 当前骨骼变换
        ↓
Canvas 前端预览 / Pillow 导出
```

`lab/models.py` 是严格 Pydantic 契约，禁止未声明字段和非有限数值。
`lab/storage.py` 按生成的 ID 读写，JSON 临时文件后原子替换，revision 避免过期覆盖。
`lab/main.py` 只运行于本地，全部写请求要求同源与专用标头；资产路由只提供指定格式 PNG，不是通用文件服务。

## 数学与绘制

待机/行走/攻击/跳跃先生成root与末端目标，求腿和手臂的两骨 IK。不能到达的目标投影到可达半径，但输出 residual 并提示，不把数值投影描述为完成接触。

行走接触在世界坐标验证，原地播放仅在最后扣除水平根位移。手臂和腿的折弯侧在 Rig 中固定。没有全身非线性优化、关节角范围或碰撞限制，模板下的大动作可能仍不自然。

素材两个图片点 A、B 映射到骨骼原始长度方向。单位像素缩放根据 bind 长度固定，不跟随当前端点距离变化。用户旋转、缩放、偏移在绑定层应用，不能污染原始 PNG。武器骨骼起点为右腕，角度来自模板或校正轨道。

前端使用后端给定的6元素绘制矩阵；关节编辑预览使用对应 JS 计算。Pillow 输出使用逆矩阵做采样。用整段固定相机，不按 Alpha bbox 每帧适配。潜在裁切通过 Alpha bbox 变换后保守检测，导出默认拒绝可能裁切的素材。

## 为什么没有直接导出 Spine

本实验使用自定义二维骨架与刚性附件格式，目的是独立验证动作生成。不能只写一个 skeleton.version 就当作生产 Spine 文件。若效果通过，再根据目标版本与许可做适配器；本项目不分发 Spine runtime。
