# Rig Motion Lab 0.4 · 多帧联动与编辑影响范围

## 为什么以前要逐帧改

0.3 把模板转换为完整姿势后，默认每个输出采样点就是一个姿势关键帧。
修改其中一帧，只改这一帧，下一帧仍然保持旧姿势。0.4 新增时间影响权重：
**让每个受影响的姿势保留自己的运动，仅叠加本次修改的位移或旋转差量。**
不复制整个人到每一帧，不重新运行旧模板，也不调用图片 API。

## 使用

`git pull --ff-only origin main` 后重启 Python，浏览器强制刷新。
页头应显示 **EDITOR 04**。先在「动作实验」选择动作；若尚未转换，点击
「将当前模板转为可编辑关键帧」。在右侧「编辑影响范围」选择作用范围：

| 范围 | 行为 | 使用场景 |
|---|---|---|
| 仅当前姿势 | 改当前一个关键帧；已链接循环边界时联动另一边界 | 局部精修 |
| 附近一段（默认） | 当前时刻影响最大，向前后衰减；半径按动作时长百分比设置 | 修正挥击附近、抬脚阶段 |
| 指定区间 | 设定起止时间，区间必须包含当前时刻 | 只改蓄力、落地等阶段 |
| 整个动作 | 所有姿势等量应用本次差量，保留各帧原有变化 | 整段手臂抬高、头部倾斜或根偏移 |

默认是附近一段、前后各 20%、平滑衰减、100% 修改强度。
支持平滑、线性和等量三种权重；「整个动作」不使用范围衰减。
例如在 50% 时刻把头旋转 20°：当前姿势加 20°，附近姿势按权重加较小的角度；
选择整个动作后，每帧在原来的头部角度上加 20°，**不是所有帧都变成绝对 20°**。

数值输入仍表示当前时刻希望到达的位置或局部角度。程序计算「输入值减去当前值」，
把这个差量分配给其它姿势。强度 50% 会只应用一半的修改量。
骨架和角色图上的拖拽同样支持影响范围，按下指针时固定本次的范围和动作快照。
拖动中预览，不写工程；松开时一次保存全部受影响姿势，取消手势不保存。

时间轴背景色带显示影响包络，菱形亮度显示关键帧的权重，面板显示实际影响数量。
动作本来只有少量稀疏关键帧时，影响范围内能修改的关键帧也较少。
**作用范围针对姿势关键帧**，帧间仍用既有插值；影响过的关键帧可能改变相邻插值段，
不宣称连续时间上范围外每个像素严格不变。若当前时间不是关键帧，会插入一个姿势；
插入也可能改变原平滑/保持段的插值。姿势数达到 129 时拒绝额外插入，不静默删帧。

## 重设上次影响，而不是重复叠加

一次调姿后可以改变范围、衰减或强度，再点「重设上次修改的影响范围」。
它回到**上次修改之前的快照**重新计算：先增加 20°，然后改成 50% 强度，
结果为原动作加 10°，不是先加 20° 再加 10°。重设为 0% 可恢复该次修改前的姿势。

只在同一工程、同一动作、且没有其它工程修改时可重设。修改其它数据、切换动作、
撤销/重做或重开页面后，旧记录可能失效，按钮将禁用，避免覆盖后续修改。
普通新调姿则以当前动作作为新的基线，允许有意叠加。

每次整批操作只产生一次工程写入和一个撤销步骤。
Ctrl/Cmd+Z 一次撤销整批，Ctrl/Cmd+Shift+Z 重做。
影响范围设置与「上次修改」快照是页面会话工具状态，不是新的持久化动画层。
最终修改后的 pose_keys 正常保存于工程、工程 ZIP 与 motion.json 中。

## 结构与接触边界

FK 将选中骨骼的局部角度差量加到各帧，子骨骼自然跟随，不修改子骨骼自己的角度。
IK 对各帧原来的手腕/脚踝位置分别加位移，重新求解两骨链；不会把所有手脚吸到同一点。
保持每一帧已制作的肘膝弯曲侧；极接近伸直时使用已确认骨架的弯曲侧。
不可达目标会限制在骨长可达范围并报告误差，不拉长骨骼。

骨盆平移会移动整个角色，不自动把脚留在原地。
接地帧的原脚部目标与接触记录保留用于诊断，不能改个目标就冒充“锁脚成功”。
其它位置目标保存本次请求位置。FK、IK 和骨盆联动都不是全身接触求解器；
编辑后仍应检查脚底、武器轨迹、遮挡和碰撞。关节骨长保持，但不保证动作变得自然。

循环动作启用「链接循环首尾姿势」时，0% 和 100% 边界应用相同差量一次，
不复制根前进位移、脚接触编号或无关骨骼。附近联动可以跨越首尾，
例如在 0% 修改时同时影响结束附近；不会修改循环中间的姿势。
这保留原有姿势的首尾关系，不修复原先已经存在的循环不连续，也不保证速度连续。
斩击/跳跃等非循环动作不跨越首尾。原初始骨架、素材、相机、层级和其它动作均不修改。

部件的 Alpha 高亮、图中选择、Alt 轮选和遮挡层级继续保留；高亮不会进入导出。

## 实现与验证

- `lab/static/motion-influence.js`：无 DOM 的纯数值批量编辑器，不可变输入与原子校验。
- `lab/static/influence-editor.js` / `.css`：范围、强度、色带、上次影响重设及一次保存。
- `template-editor.js`：数值与拖拽进入同一多帧编辑流程；记录/复制/移时仍是原有操作。
- 不新增持久化字段、不改变原有本地 Host/Origin/版本冲突保护，不需要新运行依赖。

本轮自动测试 172 项通过，含 55 项新增：真实浏览器计算模块在 Node 中执行，
结果通过 Python 模型验证、求解与导出；Node 只用于测试，不是运行工具所需依赖。
额外完成 33 项新 Chromium 界面桥接检查、39 项旧编辑器回归、9 项本机 HTTP 检查。
Chromium 原生 localhost 导航受环境策略阻止，界面检查采用 DOM + Python HTTP 桥接，
不是原生浏览器网络端到端测试。截图为内置分层素材，不是用户角色的美术效果验证。

测试记录：`editor04-tests.txt`、`editor04-browser-results.json`、`editor04-http-results.json`。
